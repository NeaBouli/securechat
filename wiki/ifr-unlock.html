IFR Integration Status

No wallet code runs inside the Android app. IFR ownership verification happens only in the browser before purchase.

Current state

  • The sales page connects MetaMask, Phantom, Coinbase Wallet and other WalletConnect-compatible Ethereum wallets.
  • The wallet signs a one-time ownership message; no manual wallet-address proof is accepted.
  • The server checks IFR read-only on Ethereum Mainnet and opens an eligible 50% checkout only when the secure payment backend is available.
  • Any positive IFR balance is eligible for the seller-defined discount displayed at checkout; there is no token-amount tier threshold.
